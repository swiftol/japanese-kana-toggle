# 日语假名开关 0.1.3

这是一个独立的 Chromium 浏览器扩展。仅在用户主动启用的网站运行；现有 B 站语言助手保持独立。

## 使用

1. 加载扩展目录后，打开一个普通的 HTTP 或 HTTPS 网页。
2. 点击扩展图标，选择“在此网站启用”，即可使用，不再逐站询问。安装或更新时浏览器可能要求一次性确认所有网站权限。
3. 点击页面中的日语文字，汉字后会显示假名；再次点击已标注的文字恢复原文。选择文字时不会触发。
4. 链接保留普通点击跳转：电脑按住 Alt 点击链接文字显示或恢复假名；手机长按链接文字切换。手机浏览器需支持此类扩展。
5. 扩展面板可切换“整页显示假名”，也可选择“全部恢复原文”；关闭网站开关会恢复当前页面并停止在该网站运行。

设置按网站来源保存，重新打开页面后会继续生效。整页模式会处理包含假名的文字或语言标记为日语的文字，尽量不误改中文；单独点击纯汉字文字时也会尝试标注。

## 原理与限制

使用随扩展附带的 Kuromoji 日语分词器和 IPADIC 词典，在本机分析语句并推断读音，不向翻译服务发送网页文本。这不是 Yomichan；Yomichan/Yomitan 是弹出式词典扩展。

多音字、专有名词、新词和上下文容易产生误读。无法识别图片、视频画面、关闭的 Shadow DOM 或未授权的跨域 iframe 中的文字，也不会修改输入框、编辑器或代码块。浏览器内部页面、扩展页面及 PDF 阅读器等受保护页面无法使用。为避免卡顿，单个超过 100,000 字符的文本节点不会自动处理。

## 加载到 Edge

打开 `edge://extensions/`，启用开发人员模式，选择“加载解压缩的扩展”，选择本目录（包含 manifest.json 的目录）。浏览器必须支持 Manifest V3。扩展申请全部普通网站的访问权限，但只在主动启用的网站运行；浏览器可能在安装或更新时要求确认。

## 测试

使用独立 Chromium 配置测试了单段切换、整页、动态内容、页面刷新、站点停用与重新启用、中日混排、链接、开放 Shadow DOM、模拟触屏长按，并在日语维基百科进行了单段切换测试；权限授权弹窗本身未在真实手机上验证。
